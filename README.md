# ModernOculus

ModernOculus is a community fork of [Oculus](https://github.com/Asek3/Oculus), which is an unofficial Forge port of [Iris Shaders](https://irisshaders.net).

This fork aims to continue maintenance and improvements of the Oculus codebase for the Minecraft modding community.

## Disclaimer
ModernOculus is not and never will be compatible with OptiFine!

## Dependencies
ModernOculus requires [Embeddium](https://modrinth.com/mod/embeddium) for good performance.

## Features
* Performance. ModernOculus should fully utilize your graphics card when paired with optimization mods like Embeddium.

* Mod compatibility. ModernOculus should make a best effort to be compatible with modded environments.

* Backwards compatibility. All existing ShadersMod / OptiFine shader packs should just work on ModernOculus, without any modifications required.
